# Privacy Policy

This application ("The Accountant") is a personal, self-hosted home finance tool.

- **Data collected:** Bank transaction data fetched via the Enable Banking API from accounts owned by the operator.
- **Data storage:** All data is stored locally on the operator's own hardware. No data is shared with third parties.
- **Purpose:** Personal budgeting and expense tracking. Non-commercial use only.
- **Access:** Single-user application. No data is accessible to anyone other than the operator.
